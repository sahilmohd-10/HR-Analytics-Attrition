# 📊 HR Analytics Dashboard – Employee Attrition Insights

## 📌 Project Overview

This project analyzes employee attrition using HR data to identify key factors driving workforce turnover. The goal is to provide actionable insights that help organizations improve employee retention and reduce attrition.

---

## 🎯 Objectives

* Analyze employee attrition trends
* Identify high-risk employee segments
* Understand impact of factors like salary, job role, overtime, and satisfaction
* Build an interactive dashboard for decision-making

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard creation & visualization
* **Python (Pandas, NumPy)** – Data cleaning & preprocessing
* **Excel/CSV** – Data source

---

## 📂 Dataset

* Source: IBM HR Analytics Dataset
* Records: 1,470 employees
* Features: Age, Department, Job Role, Salary, Overtime, Job Satisfaction, Attrition, etc.

---

## ⚙️ Data Processing

* Converted categorical attrition data (Yes/No) into numeric format
* Created new features:

  * **Salary Band** (Low, Medium, High, Very High)
  * **Tenure Band**
* Cleaned and structured dataset for analysis

---

## 📊 Key Metrics (KPIs)

* Total Employees: 1470
* Attrition Rate: 16%
* Total Attrition: 237
* Average Tenure: 7.01 years

---

## 📈 Dashboard Features

* Attrition analysis by **Department** and **Job Role**
* Salary-based attrition insights
* Gender distribution of employees
* Impact of **Overtime** and **Job Satisfaction** on attrition
* Interactive filters (Department, Gender, Salary Band)

---

## 🔍 Key Insights

* Employees working **overtime** show significantly higher attrition rates
* **Sales department** has the highest attrition among all departments
* Employees with **low job satisfaction** are more likely to leave
* Lower salary bands tend to have higher employee churn
